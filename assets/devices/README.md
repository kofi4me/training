# Generic equipment imagery

These AI-generated, unbranded product representations were created with the built-in image-generation tool for Network Workshop. They do not depict or claim compatibility with a specific manufacturer or model. The simulator's capabilities are independent of the pictured port count, hardware details, or status LEDs. Separate diagram indicators report simulated connection state.

Runtime assets are `router.webp`, `switch.webp`, and `host.webp`. The PNG files retain the generated originals. WebP files are trimmed and resized for browser delivery, preserving transparency. Include this directory when publishing to GitHub Pages. `prepare.cjs` is an optional asset-optimization helper and is not needed at runtime.
